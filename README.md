# Tic-Tac-Toe GUI Game

A two-player Tic-Tac-Toe game with a Java Swing graphical interface.

## Requirements

- Java Development Kit (JDK) 8 or later

## Run

From the project root, compile and launch the game:

```sh
javac code/TicTacToe.java
java -cp code TicTacToe
```

At startup, enter a name for each player. The game tracks scores across rounds; choose **Restart Game** to clear the board and play another round.

## Project structure

- `code/` — Java source code
- `output/` — screenshots of the running game
